# Advisory data

One JSON file per CVE. Initial records reference the PHP security release announcement dated 21 October 2026. The archive lists fixed releases 8.5.12, 8.4.27, 8.3.36, and 8.2.35: https://www.php.net/archive/2026.php

The fixed_by mapping is version-only and cannot account for vendor backports. Review official notices before making production decisions.
